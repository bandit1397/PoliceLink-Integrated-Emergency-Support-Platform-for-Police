# 🚨 PoliceLink — 경찰 통합 긴급지원 플랫폼 (1차 시험판)

**순찰차 배치 · 통역원 호출 · 금융기관 협조 · 유관기관 지원** 요청을 하나의 웹앱에서 보내고,
수신자의 **수락/거절 → 상황관리자 배정 → 처리 완료**까지 실시간 상황판과 Google 스프레드시트에 기록합니다.
수신자 휴대폰은 화면이 꺼져 있어도 무료 앱 **ntfy** 로 **무음 모드에서도 알람처럼** 울립니다.

**https://script.google.com/macros/s/AKfycbx7UhxhjwnyxErO3oBARbPh4dgB-CpDJA8Hz4k2uaULFHXmWIHvQ-GNZA8O6kiwEwUcIg/exec**

- 같은 주소가 역할(관리자 · 상황관리자 · 현장 경찰관)에 따라 다른 메뉴를 보여 줍니다. 코드를 고쳐 다시 배포해도 주소는 그대로입니다.
- 수신자(순찰차 · 통역원 · 기관 · 응급실)는 이 주소가 아니라 관리자가 준 **개인 링크**로 엽니다.

## 동작 방식

```
 현장 경찰관 · 상황관리자 (PC 크롬 · 갤럭시)          수신자 (개인 링크)
        │  요청 · 배정 · 완료                         순찰차 41·42·43호 · 통역원 · 금융기관 · 유관기관 · 병원 응급실
        ▼                                                   ▲  수락 / 거절 / 현장 도착 / 처리 완료
  Google Apps Script ── Google 스프레드시트 (USERS · RECIPIENTS · REQUESTS · RESPONSES · ASSIGNMENTS · AUDIT_LOG)
        │  알림 내용(요청번호 · 유형 · 긴급도)만 돌려줌
        ▼
  직원 브라우저 ──POST──▶ ntfy.sh ──▶ 수신자 휴대폰 ntfy 앱 (수신자마다 다른 토픽, 화면 꺼짐 · 무음이어도 알람)
  상황판 브라우저 ── 15초마다 확인: 1분 넘게 응답 없는 대상에게 재알림 (최대 3번)
  수신자 휴대폰에는 최근 요청 3건의 알림만 남음 (새 요청이 오면 오래된 알림부터 삭제)
```

- Apps Script 서버는 ntfy.sh 에 접속할 수 없어서(Google 차단) **브라우저가 직접** 보냅니다. 재알림도 **상황판을 켜 둔 관제 PC** 가 보냅니다.
- 알림에는 **사건 내용 · 위치가 없습니다.** 수신자는 알림을 눌러 PoliceLink 를 열어야 내용을 봅니다.
- 외부 기관(통역원 · 금융 · 유관기관)은 **자기에게 온 요청만** 보고, **내부 메모는 볼 수 없습니다.** 순찰차(내부)는 내부 메모도 봅니다.

### 수신자 관리 (관리자)

**⚙ 관리자 → 👥 수신자 · 개인 링크** 에 순찰차 · 통역원 · 금융기관 · 유관기관이 유형별로 **순번 1, 2, 3 …** 순서대로 나옵니다.

| 버튼 | 동작 |
|---|---|
| **＋ 추가** | 그 유형의 **마지막 순번 다음 번호**로 만듦 (이름 기본값 예: `통역원 5`, 고쳐도 됨) → 저장하면 **개인 링크가 바로 발급** |
| **복사** | 개인 링크 복사 (복사가 막힌 브라우저는 링크 칸을 눌러 선택 → Ctrl+C) |
| **수정** | 이름 · 소속 · 언어/상세 · 구역 · 상태 · 일시 중지 변경, **링크 재발급** (유형은 바꿀 수 없음) |
| **삭제** | 두 번 눌러 삭제 → 링크 **즉시 무효**, 목록 · 알림 대상에서 빠짐. 지난 요청 · 감사기록의 이름은 남고, **번호는 다시 쓰지 않음** (4번 삭제 후 추가하면 5번). 처리 중인 배정이 있으면 삭제 안 됨 |

### 순찰차 추천 (GPS 없는 1차)

가장 가까운 차가 아니라 **가용(+100) · 담당 구역 일치(+30) · 진행 중 임무(건당 −40) · 휴식(−50)** 으로 점수를 매겨 정렬하고,
긴급이면 상위 2대 · 보통이면 1대를(가용 차량만) 미리 선택합니다. **최종 배정은 상황관리자**가 수락한 차량 중에서 누릅니다.
배정되면 그 순찰차는 자동으로 `출동중`, 완료 · 취소되면 `가용` 으로 돌아갑니다.

## 설치 (관리자 1회, 약 10분)

1. https://script.google.com → **새 프로젝트** (이름 예: `PoliceLink`)
2. 기본 `Code.gs` 를 지우고 [`Code.gs`](Code.gs) 내용 붙여넣기
3. **파일 ＋ → HTML** → 이름 `Index` → [`Index.html`](Index.html) 내용 붙여넣기
4. (선택) **프로젝트 설정(⚙) → "appsscript.json 매니페스트 파일 표시"** → [`appsscript.json`](appsscript.json) 내용으로 바꾸기 (시간대 Asia/Seoul)
5. 위쪽 함수 목록에서 **`setupDemo`** 선택 → **실행** → 권한 승인
   - 내 드라이브에 `PoliceLink 데이터 (시험용 · 가상 데이터만)` 스프레드시트와 7개 시트가 생깁니다
   - **실행 로그**에 `admin` · `sit01`(상황관리자) · `p4101`(현장 경찰관) 의 **PIN** 이 나옵니다 → **지금 적어 두세요** (다시 볼 수 없음, 관리자 화면에서 재발급은 가능)
   - 가상 수신자 12곳(순찰차 41·42·43호, 통역원 4, 금융 2, 유관기관 3)이 들어갑니다
   - 가상 데이터 없이 관리자만 만들려면 `setup` 을 실행
6. **배포 → 새 배포 → 유형: 웹 앱** — 실행 계정: **나** · 액세스 권한: **모든 사용자**
   (외부 수신자가 Google 로그인 없이 개인 링크로 들어와야 하므로. 대신 직원 PIN · 개인 링크로 막습니다)
7. 배포된 **웹 앱 URL(`…/exec`)을 한 번 엽니다** → 이 주소가 저장되어 알림 버튼 · 개인 링크에 쓰입니다

> 코드를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포** (같은 /exec 주소 유지).

|---|---|---|---|
| 1 | **이 휴대폰이 요청 대상이었나** — 휴대폰에 연 개인 링크가 어느 수신자인지, 요청의 **알림 대상** 에 그 수신자가 체크됐는지 | 관리자 → 수신자 (링크 비교) · 상황판 요청 카드의 대상 목록 | ✅ 원인. 휴대폰 링크는 `통역원 5`(인도네시아어), 몽골어 요청은 몽골어가 등록된 `통역원 C` 에게만 감 → 통역원의 **가능 언어**에 그 언어가 있어야 대상이 됨 |
| 2 | **ntfy 앱이 그 수신자의 토픽을 구독했나** | 휴대폰 ntfy 첫 화면 '구독한 주제' 에 `pl-…` 이 있는지 | ✅ 원인. 병원 시스템 토픽만 있고 PoliceLink 토픽 없음 → 수신자 화면 **🔔 내 알림 구독** 을 눌러 해결 |
| 3 | **즉시 전달이 켜져 있나** | ntfy → 그 주제 → ⋮ → 구독 설정 → 즉시 전달 | 꺼져 있었음 (Firebase 경유는 늦거나 빠질 수 있음) → 켬 |
| 4 | 알림이 실제로 나갔나 | 상황판 요청 카드 '재알림 n회', 보낸 화면의 "알림 n/n건 발송" 메시지 | 통역원 C 쪽으로 첫 알림 + 재알림 2회 정상 발송 확인 |
| 4-1 | 알림을 누르면 관리자 화면 · '수신자 등록이 없습니다' 안내로 열리나 | 휴대폰 | 그 브라우저에 개인 링크가 등록되지 않은 것 → 개인 링크를 **같은 브라우저**에서 한 번 열기. 알림이 다른 브라우저로 열리면 기본 브라우저를 맞추기 |
| 5 | ntfy 앱에서 그 토픽 화면을 열어 둔 채인가 | 휴대폰 | ntfy 는 **보고 있는 토픽의 알림은 알림창에 띄우지 않음** → 홈으로 나가 둘 것 |
| 6 | 인터넷 · 알람 음량 · 배터리 최적화 | 휴대폰 설정 | emergency-ntfy 휴대폰 설정 표와 같음 |

### 주요 결정

- **알림은 ntfy** (사용자 결정). 화면 꺼짐 · 무음에서도 알람, 무료, emergency-ntfy 에서 검증됨. 서버가 아니라 **브라우저가 ntfy.sh 로 보냄**
- **수신자마다 개인 링크 + 개인 토픽**. 링크 끝 열쇠는 추측할 수 없는 무작위 값 (순번 `?r=1` 방식은 다른 기관 화면을 열 수 있어 쓰지 않음). 순번은 관리자 화면에서 정리용으로만 표시
- **삭제는 '삭제됨' 표시** (시트 행은 남김) → 지난 기록 보존 · 번호 재사용 방지
- **직원은 아이디 + PIN**, 수신자는 로그인 없이 개인 링크. PIN 은 해시로만 저장
- **외부 기관 최소정보**: 내부 메모 · 요청자 아이디 · 경찰관 이름은 보내지 않음

### 다시 시작하는 방법 (다음 개발 때)

1. 이 저장소를 받습니다 (`git pull`). 로컬 폴더: `Desktop/PoliceLink — Integrated Emergency Support Platform for Police`
2. 서버 로직 시험: `node tests/test_server.js` → 마지막 줄 `ALL TESTS PASSED`
3. 시험 계정 · 개인 링크 · 데이터 시트 주소는 **PC 의 `accounts.local.txt`** (git 제외 파일. 없으면 관리자 화면 · `resetAdminPin` 으로 다시 만듦)
4. 코드를 고친 뒤: 커밋 · push → Apps Script 편집기에 `Code.gs` · `Index.html` 반영 · **저장** → **배포 → 배포 관리 → 수정 → 새 버전 → 배포** (웹앱 주소 유지)
5. 휴대폰 시험: 개인 링크 열기 → **🔔 내 알림 구독** → ntfy **즉시 전달** 켜기 → 홈으로 나가서 대기

## 보안 · 주의

- **이 저장소는 공개입니다.** 스프레드시트 ID · PIN · 개인 링크 · ntfy 토픽 이름을 커밋 · 이슈 · 문서에 쓰지 마세요 (모두 스크립트 속성과 비공개 시트에만 있음).
- 개인 링크 = 로그인 정보입니다. 승인된 경로로 본인에게만 전달하고, 분실 · 퇴사 시 **링크 재발급**(이전 링크 즉시 무효) 또는 **사용 중지**.
- ntfy.sh 는 공개 서버라 토픽 이름을 아는 사람은 알림을 볼 수 있습니다 → 알림에는 요청번호 · 유형 · 긴급도만 넣습니다.
- 요청 · 감사기록 정리: 편집기에서 `clearRequests` 실행 (직원 · 수신자는 남김).
