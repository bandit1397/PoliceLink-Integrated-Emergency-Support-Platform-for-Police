알림은 에게 온 것입니다. 응답 화면을 열려면 관리자에게 받은 개인 링크를 이 휴대폰의 같은 브라우저에서 한 번 여세요. 그 뒤로는 알림만 눌러도 바로 응답 화면이 열립니다.

개인 링크를 열었는데도 이 안내가 나오면, 알림 버튼이 다른 브라우저(예: 삼성 인터넷 ↔ Chrome)로 열리는 것입니다. 휴대폰 설정 → 애플리케이션 → 기본 앱 → 브라우저 앱을, 개인 링크를 연 브라우저로 맞추세요.

수신자 추가

📱 화면이 꺼져도 알림 받기 (최초 1회)

  1. Play 스토어에서 ntfy 앱을 설치합니다 (무료, 회원가입 없음).
  2. 빠른 방법: 아래 📱 설정 파일 받기 → ntfy 앱 → 설정 → 백업 및 복원 → 파일에서 복원 → 방금 받은 파일 선택. 구독 · 즉시 전달 · 계속 울리기가 한 번에 켜집니다. 그다음 휴대폰 설정에서 ntfy 배터리 최적화만 해제하세요.
  3. 또는 하나씩: 아래 버튼으로 구독 (ntfy 앱이 열리면 구독 완료)
    🔔 내 알림 구독
    → ntfy 구독 설정 → 즉시 전달(Instant delivery) 켜기 · 배터리 최적화 해제 → ntfy 설정 → Keep alerting for highest priority 켜기 (새 요청은 긴급 · 보통 모두 응답할 때까지 계속 울림, 알림창은 새 요청이 맨 위).

🔕 알람 끄기: 알림을 누르면 바로 이 응답 화면이 열립니다 (알람은 계속 울림) → 응답 버튼을 누르면 알람이 멈춥니다 (빨간 배너는 이 화면 소리만 끔) (ntfy 화면이 잠깐 열림 → 뒤로 가기로 이 화면에 돌아옴). 응답 없이 알람만 끄려면 알림의 알람 끄기 버튼.

⚠ ntfy 화면이 열리면 반드시 ◀ 뒤로 가기 (또는 요청 카드의 🔴 PoliceLink로 돌아가기 (필수) 버튼)로 나오세요. ntfy 화면을 열어 두면 다음 알림이 휴대폰 알림창에 뜨지 않습니다. (ntfy 앱 구조상 자동으로 돌아올 수 없음)

이 구독 주소는 나에게만 오는 알림입니다. 다른 사람에게 알려 주지 마세요. 알림에는 요청번호 · 유형 · 긴급도만 담깁니다.
